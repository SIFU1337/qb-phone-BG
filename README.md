📱 Превод на qb-phone за FiveM (български език)
Този репозиториум съдържа пълен превод на qb-phone на български език, съвместим с QBCore framework за FiveM.

✨ Какво включва:
✅ Преведени всички менюта и съобщения

✅ Съобразено с граматиката и терминологията на RP сървърите

✅ Поддържа се съвместимост с оригиналния qb-phone

📦 Инсталация:
Свали файла или клонирай репозиторито:

bash
Copy
Edit
git clone https://github.com/SIFU1337/qb-phone-BG.git
Замени съществуващите езикови файлове в твоя qb-phone ресурс с тези от този репозиторий.

Рестартирай сървъра.

🛠️ Забележки:
Преводът е тестван с последната версия на qb-phone към датата на публикуване.

Ако намерите грешки или имате предложения – pull request-ите и issues са добре дошли!

📌 Лиценз:
Този проект е с отворен код и следва същия лиценз като оригиналния qb-phone. Уважавайте труда на авторите.
